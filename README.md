# نظام إدارة وأتمتة حسابات السوشيال ميديا (Basha SMM Panel & Mobile Automation Engine)

نظام متكامل واحترافي يجمع بين لوحة تحكم عصرية فاخرة (Luxury Black & Gold Aesthetics)، ومحرك أوتوميشن خفي فائق التطور يعمل في الخلفية بنظام الطابور المستمر (Continuous Queue Worker)، مع قاعدة بيانات سحابية متقدمة مبنية على Supabase (PostgreSQL).

---

## 🌟 أبرز مميزات النظام

1. **لوحة تحكم تفاعلية (Frontend Dashboard):**
   - تصميم فاخر بدرجات الأسود الصريح والذهبي الملكي (`#08080A` و `#13131A` و لمسات `amber-500`).
   - كروت إحصائيات علوية سريعة: الحسابات النشطة، تحت التحقق (Checkpoint)، المحظورة، والمهام المعلقة والمكتملة.
   - جدول الحسابات مع بادجات الحالة وصور البروفايل الحقيقية وآخر خطأ مسجل.
   - جدول طابور المهام مع دعم كامل لجميع العمليات (`like`، `comment`، `share`، `extract_profile`).
   - سجل كونسول مباشر (Live Terminal Console) لمراقبة الأوتوميشن لحظة بلحظة.
   - نافذة إعدادات مرنة لحفظ واختبار مفاتيح Supabase مباشرة من المتصفح أو عبر `.env`.

2. **محرك الأوتوميشن والتخفي (Stealth & Device Emulation Engine):**
   - محاكاة دقيقة لمواصفات هاتف **Google Pixel 5** (`Android 11`, `Touch Events`, `Viewport 393x851`, `deviceScaleFactor 2.75`).
   - محاكاة السلوك البشري (Humanization Engine): فترات تأخير عشوائية متغيرة (Jitter: 1s إلى 4s)، وكتابة النصوص حرفاً بحرف بسرعة متغيرة (40ms إلى 150ms)، وتمرير بطيء.
   - حارس نقاط التفتيش (Checkpoint Guardian): رصد شاشات التحقق في فيسبوك وحماية الحسابات تلقائياً بتجميدها وتسجيل سبب التوقف لتفادي الحظر الدائم.
   - حلقة معالجة طابور مستمرة (`while (isRunning)`) مع سكون مؤقت عند فراغ الطابور وإغلاق آمن (`Graceful Shutdown`).

3. **بنية تحتية وقاعدة بيانات (Supabase PostgreSQL):**
   - ملف مخطط SQL جاهز للتنفيذ الفوري داخل محرر SQL في Supabase (`supabase/schema.sql`).
   - فهارس مخصصة لسرعة سحب الطابور بنظام الأقدمية (FIFO Queue).
   - تريجرات لتحديث طوابع الوقت تلقائياً (`updated_at`).

## 🚀 خطوات التثبيت والتشغيل السريع

### 1. إعداد قاعدة بيانات Supabase
1. افتح مشروعك في [Supabase](https://supabase.com).
2. انتقل إلى **SQL Editor**.
3. انسخ محتوى الملف `supabase/schema.sql` والصقه في المحرر ثم اضغط **Run**.
4. انسخ `Project URL` و `service_role key` أو `anon key` من قسم **Project Settings -> API**.

### 2. ضبط المتغيرات البيئية
قم بإنشاء ملف `.env` بناءً على `.env.example`:
```bash
cp .env.example .env
```
وقم بملء البيانات:
```env
SUPABASE_URL=https://your-project.supabase.co
SUPABASE_SERVICE_ROLE_KEY=your-supabase-service-role-key
GEMINI_API_KEY=your-gemini-key
PORT=3000
```

### 3. تثبيت التبعيات وتشغيل التطبيق
```bash
# تثبيت الحزم
npm install

# تشغيل بيئة التطوير
npm run dev

# أو تشغيل الإنتاج
npm start
```
افتح المتصفح على: `http://localhost:3000`

## 🔒 حارس نقاط التفتيش (Checkpoint Guardian)
في حال طلب فيسبوك أي شاشة تحقق (مثل 2FA، أو تأكيد الهوية، أو Checkpoint)، يقوم المحرك فوراً بما يلي:
1. إيقاف المهمة الحالية لمنع تفاقم المشكلة.
2. تحويل حالة الحساب في `bot_accounts` إلى `checkpoint`.
3. تدوين سبب التوقف في عمود `last_error`.
4. تحويل حالة المهمة في `bot_tasks` إلى `failed`.
5. استبعاد وتخطي أي مهام جديدة مجدولة لهذا الحساب تلقائياً حتى يقوم المسؤول بحلها يدوياً.
