# Basha SMM - منصة إدارة وأتمتة حسابات السوشيال ميديا (React SPA)

تمت إعادة كتابة وتطوير النظام بالكامل كـ **تطبيق React متطور فائق الأداء (React SPA + TypeScript + Vite + Tailwind CSS)** يحافظ على كامل منطق العمل والميزات الحقيقية مع بنية برمجية تفاعلية حديثة.

---

## 🌟 الميزات والمكونات الرئيسية

1. **لوحة تحكم تفاعلية فاخرة (React Dashboard):**
   - واجهة مستخدم متجاوبة تدعم اللغة العربية بالكامل (RTL) بطابع التصميم الفاخر (Dark Luxury Gold Theme).
   - شريط علوي مع تحكم فوري بحالة طابور الأوتوميشن (`تشغيل / إيقاف`) وتنفيذ المهام الفورية.
   - كروت إحصائيات حية متجددة تلقائياً (الحسابات النشطة، تحت التفتيش، المحظورة، المهام المعلقة والمكتملة).
   - إدارة متكاملة للحسابات الفعلية: إضافة حساب، فحص الحساب بالمتصفح، مزامنة صورة البروفايل الحقيقية فورياً، التعديل والحذف.
   - شاشة استعراض إثباتات التنفيذ (Execution Proof Screenshots) لعرض لقطات الشاشة الموثقة لعمليات التفاعل.
   - سجل كونسول مباشر (Live Terminal Console) يوضح خطوات المحاكاة والتفاعل والتخفي لحظة بلحظة.
   - إعدادات ربط Supabase ومزامنة الجداول تلقائياً.

2. **بنية React الموديلية (Component Architecture):**
   - `src/context/AppContext.tsx`: إدارة الحالة العامة والمزامنة التلقائية والـ Toasts.
   - `src/components/Header.tsx`: الهيدر وأزرار التحكم السريعة.
   - `src/components/QuickConnectBanner.tsx`: شريط حالة المزامنة المستمرة.
   - `src/components/StatCards.tsx`: كروت المؤشرات الإحصائية.
   - `src/components/AccountsList.tsx`: بطاقات الحسابات الفعلية وصور البروفايل وفلاتر الحالة والبحث.
   - `src/components/TaskQueue.tsx`: جدول المهام المؤتمتة وإثباتات التنفيذ.
   - `src/components/LiveConsole.tsx`: كونسول مراقبة خطوات المتصفح والتفاعل البشري.
   - `src/components/modals/`: نوافذ تفاعلية للإضافة والتعديل والجدولة والإعدادات ومعاينة الصور.

3. **التقنيات المستخدمة:**
   - **React 19** + **TypeScript**
   - **Vite 6**
   - **Tailwind CSS v4**
   - **Lucide React Icons**
   - **Supabase Client** للاتصال بقاعدة بيانات PostgreSQL السحابية
   - مسارات API خادمة ومدمجة بسلاسة لدعم كافة مسارات `/api/*`.

---

## 🚀 التشغيل والتطوير

```bash
# تثبيت التبعيات
npm install

# تشغيل خادم التطوير (على المنفذ 3000)
npm run dev

# فحص التايب سكريبت والتحقق
npm run lint

# بناء نسخة الإنتاج
npm run build
```
